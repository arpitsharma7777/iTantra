# 🚀iTantra
## "iTantra—an offline multilingual voice communication system designed for low-bitrate and connectivity-constrained environments.”
## 🌟 About iTantra
iTantra is a technology-driven platform designed to address "iTantra -Indian Multilingual TTS & STT Aided Neural Transceiver Radio Access for low bitrate links". It combines modern web technologies ,intelligent processing, and an intuitive user experience to provide an efficient and accessible solution.
## 🎯 Problem
-Voice audio required high data bandwidth.
-Low-Bitrate Links cause poor quality, delay and transmission faliure.
-Direct audio transmission is inefficient over bandwidth constrained communication.
-Multilingual communication adds another layer of complexity.
## 💡 Our Solution
-User speech is processed locally using an offline multilingual STT mode.
-VAD detects active speech and removes silence or unnecessary non-speech segments.
-Recognized text is cleaned and normalized before transmission.
-Reduces the amount of data required for bandwidth-constrained communication.
-Received text is converted back into speech using an offline multilingual TTS model.
-The receiver obtains the final message as natural speech in the supported language.
